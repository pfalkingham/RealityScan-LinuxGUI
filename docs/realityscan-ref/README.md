# RealityScan reference extracts (local only)

These files are extracts of Epic Games' RealityScan documentation and Remote Command plugin
samples, kept here for convenient local reference while developing. They are Epic's
copyrighted material and are **not committed** (see `.gitignore`); only this README is.

Regenerate them from:
- the RealityScan install's `Help/en-US/appbasics/reports_*.htm` and
  `Help/en-US/tutorials/processids.htm` (HTML stripped to text), and
- Epic's Remote Command plugin samples zip
  (https://dev.epicgames.com/documentation/realityscan/samples-remote-command-plugin):
  `Specifications/RsRemoteCommandREST.yaml`, `RsRemoteCommand.proto`,
  `RsRemoteCommandNotify.proto`, `Client-Cli/sample_templates.py`.
